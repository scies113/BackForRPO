Возможности системы

CRUD матчей

Создание, просмотр, редактирование и удаление матчей. Валидация данных на сервере. Swagger-документация для каждого эндпоинта.

Прогнозы ИИ

Получение прогнозов с вероятностями для каждого матча. Кэширование результатов в базе данных для быстрого доступа.

4 роли доступа

Admin, Operator, Analyst, User — каждая роль с уникальными правами. JWT-авторизация через заголовок и HttpOnly Cookie.

Журнал аудита
